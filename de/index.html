Probleme der Objektverwaltung

Ihr Team
  • Jede neue Kraft wird von null eingewiesen
  • Nur eine Person weiß, welchen Dienstleister man anruft
  • Der Verwalter ist weg - der Plan geht mit ihm
  • Keine gemeinsame Sicht darauf, was heute passiert
Ihre Einsätze
  • Einsatz raus. Keine Ahnung, wer ihn genommen hat
  • Falsche Villa - der Chat hat die Adresse begraben
  • Arbeit erledigt. Kein Eintrag, wer oder wie viel
Ihr Geld
  • Keine klaren Wartungskosten pro Objekt
  • Belege verloren in Chats bis Monatsende
  • Auslagen ohne Rückzahlungsspur
Ihre Gäste
  • Kautionsstreit ohne schriftlichen Beleg
  • Hausregeln geschickt. Der Gast sagt, er hat sie nie bekommen
  • Wiederkehrende Gäste schreiben auf Ihre Privatnummer, um zu buchen

Alles, was Sie für die Arbeit brauchen

Vier Bereiche, die sonst über vier verschiedene Werkzeuge laufen.

Objekte

Eine Liste für Eigentümer, zugewiesenen Verwalter und die Person vor Ort. Objektdetails, Status, Kartenpunkt, Aufenthaltsdaten und Foto, damit das Team die zugewiesenen Objekte versteht.

Einsätze und Dienstleister

Legen Sie einfach die Kontakte Ihres Wartungspersonals an und buchen Sie sie per Anruf oder Nachricht. Oder laden Sie sie in die App ein - Personal kann Aufträge in der App annehmen.

Geld

Sehen Sie, was Instandhaltung in einem Zeitraum kostet, filtern Sie nach Kategorien, genehmigen Sie Rechnungen nach Zahlung. Alle Daten sind exportierbar für Ihre Budgettabellen.

Gäste

Alle Aspekte der Gästebeziehung im Blick: Stammgäste über die App zum Ortspreis einladen, Hausregeln teilen. Kaution mit jedem Abzug, keine Missverständnisse mehr.

Eine Sprache für das ganze Team

Der Verwalter schreibt den Auftrag auf Englisch, die Reinigungskraft liest ihn auf Thai, der Eigentümer sieht ihn auf Hebräisch. Jeder stellt die Sprache einmal im Profil ein - Aufträge, Chat und Nachrichten kommen automatisch in dieser Sprache.

So verbinden Sie

Erstellen Sie in der App unter Einstellungen → Agent verbinden einen Verbindungsschlüssel. Kopieren Sie die Config für Ihr OS — npx holt die Brücke. Pulse wird nicht heruntergeladen.

Mac — unverändert einfügen. /bin/zsh lädt Ihre Shell, damit npx im PATH liegt (inkl. Homebrew).

{
  "mcpServers": {
    "pulse": {
      "command": "/bin/zsh",
      "args": [
        "-lc",
        "source \"$HOME/.zshrc\" >/dev/null 2>&1; export PATH=\"/opt/homebrew/bin:/usr/local/bin:$PATH\"; exec npx -y @pulseflow/mcp"
      ],
      "env": {
        "PULSE_MCP_TOKEN": "pfmcp_…"
      }
    }
  }
}

Windows — den kurzen npx-Block behalten. Cursor sieht npx dort bereits:

{
  "mcpServers": {
    "pulse": {
      "command": "npx",
      "args": ["-y", "@pulseflow/mcp"],
      "env": {
        "PULSE_MCP_TOKEN": "pfmcp_…"
      }
    }
  }
}

FAQ

Meine Reinigungskräfte werden keine weitere App nutzen.

Sie müssen nichts Neues lernen. Sie schicken einen Link, sie öffnen ihn im Browser, und es liegt auf dem Telefon wie jede andere App. Kein Download, kein Konto, kein App Store. Sie sehen nur ihre Aufträge, in ihrer Sprache, und bestätigen mit einem Tipp. Wer WhatsApp lesen kann, kommt damit klar.

Mein Verwalter hat schon ein System. Warum wechseln?

Sie würden nicht wechseln - sie würden einen Ort hinzufügen, an dem die Aufträge, die sie schon steuern, für alle sichtbar werden. Der Chat bleibt. Was sich ändert: ein Auftrag hat einen bestätigten Status, Kosten daran und eine Historie, die nicht verschwindet, wenn jemand geht.

Alles läuft über Airbnb und Booking. Ersetzt das die?

No. Bookings stay where they are. Pulse Flow is about what happens after the booking: who cleans, what broke, what it cost, and what the guest can see. You can paste each listing’s private calendar export (.ics) from Airbnb or Booking.com into a property to pull reserved nights into the Bookings calendar. That is not a full channel API and does not replace their listings or checkout.

Was kostet es?

Privat ist für immer kostenlos. Unternehmen kostet 15 USD / Monat und umfasst 10 Teamplätze; jeder Extra-Platz kostet 2 USD / Monat. Pro addiert 9 USD / Monat auf Privat oder Unternehmen für Agent verbinden. Abrechnung läuft noch nicht, jedes Konto bekommt 3 Monate vollen Zugang — Pro inklusive — ab dem Anmeldetag.

Müssen meine Gäste etwas Kompliziertes tun?

Nein. Sie schicken ihnen einen Link. Sie öffnen ihn, lesen die Hausregeln und sehen den Kautionsstand. Kein Download, kein Konto, keine Zahlung über die App. Zahlungen gehen direkt an Sie - die App hält nur Betrag, Abzüge und Restbetrag fest, damit beide Seiten dasselbe sehen.

Kann ein Gast einen Kautionsabzug bestreiten?

Jeder Abzug wird in der App mit Grund und Datum festgehalten. Sie und der Gast sehen denselben Restbetrag. Es gibt kein „ich habe die Regeln nie bekommen“ und kein „ich erinnere mich nicht, dem zugestimmt zu haben“ - alles an einem Ort, mit Zeitstempel, für beide Seiten sichtbar.

Was, wenn ein Gast wieder buchen will?

Wiederkehrende Gäste können eine Datumsanfrage direkt über die App schicken. Sie geht an den Eigentümer oder Verwalter, ohne über Ihre Privatnummer oder eine Drittplattform zu laufen.

Was passiert, wenn ein Mitarbeiter geht?

Die Einsatzhistorie, Dienstleisterkontakte und Objektnotizen bleiben im System. Nichts geht mit dem Telefon zur Tür hinaus. Die nächste Person sieht dieselben Informationen vom ersten Tag an.

Kann ich das für ein Objekt nutzen?

Ja. Der Privat-Tarif ist für immer kostenlos und deckt ein oder zwei Objekte ab, die Sie selbst führen. Sie bekommen dieselben Funktionen - Einsätze, Ausgaben, Gäste - ohne ein Team zu brauchen.

Sind meine Daten privat?

Jeder Arbeitsbereich ist getrennt. Ihre Objekte, Ihr Team, Ihre Gäste und Ihre Finanzen sind nur für die Personen sichtbar, die Sie einladen. Gäste sehen nur, was Sie mit ihnen teilen.
