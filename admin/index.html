How to get in

Unlock on Services admin

  1. Set PROS_ADMIN_KEY on the Services app in Vercel → Environment Variables (Production), then redeploy. Without that, unlock says admin is not configured.
  2. Open Services admin and enter that string plus the word admin.
  3. Read Property ops people/orgs/villas, Services listings, referrals, and a Plausible link for site traffic.
